TAROMEG PACKAGING WEBSITE

To preview locally, open index.html in a web browser.

Upload the complete contents of this folder to the public web directory for taromeg.co.zw. Keep the assets folder and all HTML files together, preserving the folder structure.

Pages:
- index.html (Home)
- about.html
- vision.html
- products.html
- team.html
- contact.html

The contact form opens the visitor's email application and prepares a message to info@taromeg.co.zw. A server-side form service can be added later if direct website submission is required.

GITHUB UPLOAD (WEB BROWSER)
1. Sign in at github.com and open your website repository.
2. Select Add file, then Upload files.
3. Extract this ZIP file on your computer.
4. Drag all files and the assets folder from inside taromeg-website into the repository root.
5. Enter "Rebrand Taromeg website" as the commit message and select Commit changes.
6. For GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root) > Save.

GITHUB UPLOAD (COMMAND LINE)
1. Run: git clone YOUR-REPOSITORY-URL
2. Copy the contents of taromeg-website into the cloned repository.
3. Run: git add .
4. Run: git commit -m "Rebrand Taromeg website"
5. Run: git push origin main
